safetensors 参数布局查看器

只下载文件头，把模型权重在文件里的排布画出来。纯前端，数据不经过任何服务器。

快速试试：
访问令牌（仅私有或需授权的仓库才需要）
令牌只在你的浏览器里使用，直接发给所选站点，不会经过第三方。
可以一次选中多个分片文件（model-00001-of-0000N.safetensors）。浏览器只读取文件开头的几十 KB，几十 GB 的文件也是秒开。
服务器需要支持 HTTP Range 请求，并允许跨域访问（CORS）。
8 字节
头长度 N
N 字节 JSON 头
（本工具只读这两段）
张量数据区（不下载）
safetensors 开头 8 字节是小端 uint64，表示紧随其后的 JSON 头有多长。JSON 头里记录了每个张量的 dtype、shape 和它在数据区中的字节区间。所以两次 Range 请求就够了。

条长表示
每行是一层，同一行里按文件中的先后顺序堆叠。Transformer 的各层通常完全一样，一眼就能看出是否有例外。比例尺按各层定，超出的行（一般是词嵌入）在右端画断口，真实数值标在行尾。
